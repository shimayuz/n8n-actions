# GitHub Integration Guide

## Overview

Complete guide for integrating n8n Actions with GitHub workflows, including Issues, Pull Requests, Actions, and automated deployment pipelines.

## GitHub Actions Setup

### 1. Workflow Configuration

Create `.github/workflows/n8n-actions.yml`:

```yaml
name: n8n Actions Workflow Compiler

on:
  pull_request:
    types: [opened, edited, synchronize]
  issues:
    types: [opened, edited, labeled]

jobs:
  generate-workflow:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Setup Node.js
        uses: actions/setup-node@v3
        with:
          node-version: '18'
      
      - name: Install Dependencies
        run: npm ci
      
      - name: Generate n8n Workflow
        env:
          ANTHROPIC_API_KEY: ${{ secrets.ANTHROPIC_API_KEY }}
        run: node .github/scripts/generate-workflow.js
      
      - name: Validate Workflow
        run: node scripts/validate-workflow.js
      
      - name: Commit Changes
        if: success()
        uses: EndBug/add-and-commit@v9
        with:
          add: 'workflows/*.json'
          message: '🤖 Generated n8n workflow via n8n Actions'
```

### 2. Secret Management

Required GitHub Secrets:
- `ANTHROPIC_API_KEY`: Claude API access
- `N8N_API_KEY`: n8n instance API key
- `N8N_WEBHOOK_URL`: n8n webhook endpoint

### 3. Auto-PR Creation Script

`.github/scripts/create-pr.js`:

```javascript
const { Octokit } = require('@octokit/rest');

async function createPR(workflowName, branchName) {
  const octokit = new Octokit({
    auth: process.env.GITHUB_TOKEN
  });

  const pr = await octokit.pulls.create({
    owner: context.repo.owner,
    repo: context.repo.repo,
    title: `feat(workflow): Add ${workflowName}`,
    head: branchName,
    base: 'main',
    body: `## 🤖 Auto-generated n8n Workflow
    
### Workflow: ${workflowName}

Generated by n8n Actions based on issue requirements.

### Changes
- Added new workflow: \`workflows/${workflowName}.json\`
- Validated JSON structure
- Tested node connections

### Testing
- [ ] Import tested in n8n
- [ ] All nodes configured
- [ ] Error handling verified

---
*Generated by n8n Actions*`
  });
  
  return pr.data;
}
```

## Automated Testing

### 1. Workflow Validation Action

```yaml
name: Validate n8n Workflows

on:
  push:
    paths:
      - 'workflows/*.json'

jobs:
  validate:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Validate All Workflows
        run: |
          for file in workflows/*.json; do
            echo "Validating $file"
            node scripts/validate-workflow.js "$file"
          done
      
      - name: Test Import
        run: |
          curl -X POST ${{ secrets.N8N_WEBHOOK_URL }}/test-import \
            -H "Content-Type: application/json" \
            -d @workflows/*.json
```

### 2. Integration Tests

```javascript
// .github/tests/integration.test.js
const { validateWorkflow } = require('../../scripts/validate-workflow');
const fs = require('fs');

describe('Workflow Integration Tests', () => {
  test('All workflows should be valid', () => {
    const files = fs.readdirSync('./workflows');
    files.forEach(file => {
      if (file.endsWith('.json')) {
        const workflow = JSON.parse(fs.readFileSync(`./workflows/${file}`));
        expect(validateWorkflow(workflow).valid).toBe(true);
      }
    });
  });
});
```

## Deployment Pipeline

### 1. Auto-Deploy to n8n

```yaml
name: Deploy to n8n

on:
  push:
    branches: [main]
    paths:
      - 'workflows/*.json'

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - name: Deploy Workflows
        run: |
          for file in workflows/*.json; do
            curl -X POST "${{ secrets.N8N_API_URL }}/workflows" \
              -H "X-N8N-API-KEY: ${{ secrets.N8N_API_KEY }}" \
              -H "Content-Type: application/json" \
              -d @"$file"
          done
```

### 2. Rollback Mechanism

```yaml
- name: Rollback on Failure

  run: |
    git revert HEAD
    git push origin main
```

### 1. Webhook Handler

```javascript
// api/github-webhook.js
exports.handler = async (event) => {
  const payload = JSON.parse(event.body);
  
  switch(payload.action) {
    case 'opened':
      if (payload.issue) {
        await handleIssueOpened(payload.issue);
      }
      break;
    case 'created':
      if (payload.comment) {
        await handleComment(payload.comment);
      }
      break;
  }
};
```
